# CODE ORCHESTRA — 60秒 発表台本

## 事前準備（発表の前に1回、約1分）

1. iTerm2 のウィンドウを横110桁以上の大きめにする（Pane が会話の横に並ぶ）
2. `scripts/sound-check.sh` でスピーカーから音が出るか確かめ、Mac の音量を調整する
3. `scripts/start.sh` を実行 → Claude Code が開き、右側に CODE ORCHESTRA の Pane が出る
4. `/orchestra` と入力して Enter（Pane にキーボードが渡る）
5. 本番では `p` を押すだけで始められる状態で待機する

※ 万一 REPLAY が始まらないときは `d`（DEMO）に切り替える。台本は同じ流れで使えます（DEMO のときは「人工の台本です」と言う）。

## 補足（質問が来たら）

- **音はどこで作っているか:** 自作のシンセを Node で1本のサンプルクロック上で合成し、ffplay 1プロセスに流しています。ネット接続、API、生成モデルは使いません。
- **映像の同期:** エンジンは各16分音符を「その音が聞こえる時刻」に Mod へ通知し、Mod はそれに合わせて Raster を描き直します。
- **ちゃんとした記録か:** REPLAY のイベントは、Mod が実際の CLI セッションで記録したものです。保存しているのはイベントの種類と時刻だけです。DEMO は人工の台本で、画面にもそう表示しています。
- **Claude の作業を邪魔しないか:** フックは観測だけで、ツールの結果は変えません。音の処理を待つこともありません。
